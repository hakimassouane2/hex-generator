# 02 — Points d'intérêt

Après les biomes, **un point d'intérêt** est généré pour chaque hexagone. Il peut y avoir d'autres éléments dans la zone, mais moins intéressants, cachés ou à découvrir.

## Hexagone de départ (campagne traditionnelle)
Pour une campagne classique (explorer un donjon, puis les contrées sauvages aux niveaux plus élevés) :
- **1er hexagone** = toujours un **Village**.
- **2e hexagone** = toujours un **Donjon**.

Sinon : utiliser la table des peuplements (ou choisir) pour le 1er hexagone, et la table des points d'intérêt pour les autres.

### Catégories de peuplements
- **Civils** : Hameaux, Villages, Villes — commerce, repos, soins, provisions, recrutement.
- **Liés à une classe** : Châteaux (Guerriers), Tours (Magiciens), Abbayes (Clercs). Chacun incarne le pouvoir d'une **faction** (PNJ ou PJ retraité niveau 9+).

> Note factions : **seuls** Villes, Châteaux, Tours, Abbayes (parmi les peuplements) créent une faction sur la carte. Hameaux et Villages **n'en créent pas**. (Voir `05-factions.md`.)

## Légende (symboles)
Point de repère · Hameau · Village · Ville · Château · Tour · Abbaye · Repaire · Donjon.
Avec l'extension Factions, les châteaux ont un symbole par titre (fief, baronnie, vicomté, comté, marche, duché, principauté).

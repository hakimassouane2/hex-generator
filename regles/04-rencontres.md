## Rencontres aléatoires (contrées sauvages) - 2d6 (livre p. 14)

| 2d6  | Résultat                                                    |
| ---- | ----------------------------------------------------------- |
| 2    | **Dragon** (livre p. 121)                                   |
| 3    | **Autre faction** (liée à une faction d'un hexagone proche) |
| 4-6  | **Faction** (liée à la faction de l'hexagone actuel)        |
| 7    | **PNJs** (plus ou moins amicaux, sans faction apparente)    |
| 8-11 | **Biome** (tirer un monstre sur la table du biome)          |
| 12   | **Magicien** (livre p. 144)                                 |

- **Dragon** / **Magicien** : le **prochain repaire/tour** généré(e) devient leur demeure.
- Si l'hexagone est **contesté** : 1d6 → `1-4 Une seule faction` · `5-6 Plusieurs`.
- S'il n'y a pas de faction dans l'hexagone : utiliser une faction d'un hexagone adjacent, ou tirer une rencontre de biome.
- **Biome** : monstre sans faction.

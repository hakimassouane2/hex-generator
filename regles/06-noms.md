# 06 — Noms de peuplements (livre p. 28-31)

Pour **hameaux, villages, villes**. (Châteaux et abbayes : générateurs dédiés dans leurs sections.)

## Procédure
1. Lancer **1d30** sur la table des **patrons** ci-dessous.
2. Lancer sur la/les table(s) de **composants** (A = Bâtiments/Extérieur, B = Noms communs) selon le patron. Choisir la variante la plus appropriée.

## Patrons (1d30)
Légende des lettres : **A** = composant A · **B** = composant B (nom commun) · **C, D, E, F, G, H** = autres lettres-variables représentant un composant (le PDF n'en explicite pas chaque sous-table ; en pratique on pioche dans A ou B selon le sens). « † » = des variations existent (le trait d'union ou le mot-lien peut devenir « -le- », « -la- », « -les- », « -l' »).
